Tokens on Track privacy policy

Updated September 19, 2026 · Tenjin Tech

Tokens on Track displays usage from AI provider accounts you connect. It has no developer-operated account, analytics service, advertising, or tracking.

Credentials and connections

The app reads your Claude Code login from macOS Keychain. The App Store build reads Codex and Cursor login files only from folders you explicitly allow. It never writes to those providers’ credential stores. Folder permissions are stored as macOS security-scoped bookmarks and can be removed in Settings.

API keys you enter for OpenRouter or Cursor are stored in this Mac’s Keychain. You can remove those saved keys in Settings. The direct-download build can also discover credentials from local provider files, environment variables, and supported Conductor processes. The App Store build does not inspect other processes or their environments.

Network requests

Credentials are sent to the corresponding provider to request your account’s usage: Anthropic, OpenAI, OpenRouter, or Cursor. Requests include the information needed to authenticate, such as account identifiers, tokens, or session cookies. Providers receive your IP address and handle these requests under their own privacy policies. Tenjin Tech does not receive your credentials or usage readings.

The app does not read conversation content, prompts, or source code.

Data on your Mac

Preferences, folder permissions, notification state, and a cache of usage readings are stored locally. Usage readings can include plan names, limits, spending, and reset times. Notifications are handled by macOS. The App Store build keeps its files in its app container.

Support

If you contact us, we receive the information you choose to send. GitHub issues are public: never include API keys, login files, or other private account details. See the support page for questions and privacy requests.
